# HEIM 家庭能源管家

面向德国光伏储能三口之家的中文网页 App Demo。包含「我的家」「24 小时计划」「家庭设置」三个主导航。

## 启动

安装 Node.js 22 或更高版本，在本目录执行 `node server.js`，访问 http://127.0.0.1:4178 。无须安装依赖。

## 演示顺序

1. 首页查看能源流及预计节省；切换三种用电偏好。
2. 开启「模拟明日强风」，观察备电目标从 30% 变为 65% 与计划重算。
3. 在「24 小时计划」点选任意时段查看原因；安排次日 7 点前完成洗衣。
4. 点击「模拟应用计划」获取本地模拟回执；修改设置会使旧回执失效。
5. 在「家庭设置」调整晚餐时间、关键设备和最低保障时长，查看结果联动。
6. 回首页暂停调度，确认模拟应用已禁用；恢复后可再次应用。

## 数据与计算边界

所有设备、电价、天气和收益为模拟，未接入真实硬件/API。示例日期为2026-09-25。
10 kWh 电池，初始电量68%，电量上限95%，充放电上限2.5kW，充电效率95%、放电效率90%。
动态规划使用每小时/0.1kWh粒度，优化整日电费和循环惩罚。电费对比为相同输入下的固定自用策略；优化后日末电量不低于基线。模拟价格含税、固定售电价0.08欧元/kWh；收益不含固定费用或真实电池折旧。
洗衣要求1kWh、连续2小时，调度选择截止前最低价窗口。状态仅在当前会话保存，刷新恢复默认。
备电前提为相应硬件具备离网供电能力和配套接线；此处仅为演示假设。
